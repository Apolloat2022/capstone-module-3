# Module 3 Capstone: AI-Driven Automated Support Agent

Build an AI support agent integrated with a mock ERP system that validates actions via human approval gates before executing API writes.

Starter repository for the **Apollo University** Forward Deployed Engineer
program. Operated by Apollo Technologies US.

## How to use this

1. **Fork** this repository to your own account. Do not clone and push here.
   Submissions are reviewed from your fork.
1. Build your solution. Structure is yours; `src/` and `docs/` are a starting
   point, not a requirement.
1. Write your `docs/DECISIONS.md` as you go (see below). It carries as much
   weight in review as the code.
1. Submit your **public** fork URL at
   <https://fde-course-45vy.vercel.app/capstones>.

One live submission per module. You can resubmit until it is approved.

## What is being assessed

This is a Forward Deployed Engineering programme, so the review weighs judgement
alongside implementation:

- **Does it work against realistic input?** Handling the happy path only is the
  most common reason a submission comes back with changes requested.
- **Are the failure modes handled deliberately?** Name what you chose not to
  handle and why. An acknowledged gap reads very differently from an
  unnoticed one.
- **Can a client follow your reasoning?** Trade-offs stated plainly beat an
  elegant solution nobody can follow.
- **Is it reproducible?** A reviewer should get it running from your README
  alone, on a clean machine.

## Required: docs/DECISIONS.md

Short is fine. Cover:

- The constraints you assumed, and which you invented because the brief left them open
- Each significant trade-off, and what you gave up
- What you would do differently with production traffic or a real client deadline
- Known limitations. State them; do not let the reviewer find them first

## Getting help

Questions go to your cohort channel. Reviewers give written feedback on every
submission, including approvals.
